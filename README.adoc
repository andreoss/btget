= btget

Command-line torrent downloader: point it at a torrent file or a
magnet link and it downloads the content into a directory.

== Build

  cargo build --release

== Usage

  btget <torrent-file | magnet-link> [-o dir] [options]

See btget --help for the option list.

== Features

* bencode decoding and encoding
* torrent file parsing
* magnet link parsing
* HTTP tracker announces
* peer wire protocol
* piece verification and multi-file storage
* UDP trackers and tiered failover
* multi-peer swarm downloads with rarest-first scheduling and reciprocal upload
* progress reporting and distinct exit codes
* magnet metadata exchange from peers
* DHT peer discovery for trackerless magnets
* resume of interrupted downloads
* privilege reduction via pledge where the platform provides it
* IPv4 and IPv6 trackers and peers
